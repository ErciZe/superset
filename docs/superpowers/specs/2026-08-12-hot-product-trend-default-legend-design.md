# 爆品指数趋势默认图例设计

## 目标

三个“指标整体趋势”图表在首次加载时仅展示“爆品指数”“销售额”“毛利润”，其余八个指标继续出现在图例中，但默认关闭。用户仍可逐项开启或关闭。

## 实现边界

- 保留生产看板现有布局，尤其是用户已调整的“说明文档”位置；发布时不导入或更新 Dashboard YAML。
- 在 Mixed Timeseries 已有 `echart_options` 安全解析链中，仅允许静态 `legend.selected: Record<string, boolean>`。
- 继续拒绝函数、表达式和非布尔选择值，不扩大其他 ECharts 配置权限。
- 三张趋势图的资产参数写入完整的 11 项选择映射；仅“爆品指数”“销售额”“毛利润”为 `true`。
- 不修改 Superset 后端、Dashboard CSS、数据集、查询上下文、指标口径或布局拓扑。

## 验收

- 安全解析器保留静态布尔选择映射，并拒绝动态值。
- Mixed Timeseries 最终 ECharts legend 收到相同的 `selected` 映射。
- 三张趋势图生成参数完全一致，且仅三个目标指标默认开启。
- 生产只更新三张趋势图配置并发布包含该前端修复的镜像；当前 Dashboard 布局保持逐字节不变。
- 浏览器分别检查天、周、月 Tab：11 个图例均存在，只有三个目标系列处于激活状态。
