# 爆品指数表格隐藏每页条数设计

## 目标

在“拉杆箱在售产品爆品指数看板”中移除所有表格顶部的“每页条数”控件，保留现有数据查询、排序、汇总、横向滚动和表格行展示行为。

## 范围

- 覆盖爆品指数主看板内的 SPU维度、SKU维度、国家、SPU开发经理、型号和 SPU销量排行榜表格。
- 不修改说明文档看板。
- 不修改 Superset Table 插件或其他看板。
- 不修改数据集、SQL、筛选器、指标口径和资产 UUID。

## 实现

在主看板导出元数据的 `css` 字段中加入看板级样式：

```css
.dt-select-page-size {
  display: none !important;
}
```

该选择器只在当前看板作用域内生效。表格仍按原参数取数；仅隐藏“每页条数”标签和选择框，不通过前端全局改造引入额外行为。

## 验收

1. 资产生成测试断言主看板包含该 CSS，说明文档看板不包含。
2. 既有爆品指数单元测试和资产 ZIP 校验通过。
3. 生产仅导入更新后的 Superset 元数据，不构建镜像、不重启容器。
4. Chrome 逐项检查六张表均不再展示“每页条数”，表格数据、汇总行、滚动和筛选响应正常。
5. 发布前保留元数据回滚包；生产 API、资产拓扑和健康检查通过后完成交付。

## 回滚

重新导入发布前导出的看板元数据，恢复主看板原 `css` 字段。
