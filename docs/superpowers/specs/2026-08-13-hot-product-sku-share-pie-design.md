# 爆品指数 SKU 销售比例饼图设计

## 目标

将主看板的 `SKU销售比例` 从矩形树图调整为与 `SPU销售比例` 一致的原生 ECharts 环形饼图。

## 设计

- 保持图表名称、UUID、数据集、看板布局和资产数量不变。
- 使用现有 `_pie_params("sku", legend_type="plain")`，不新增重复的 SKU 专用参数生成器。
- 继续按 `sku` 分组，以中文指标 `销量` 降序查询。
- 展示 SKU 与销量占比，中心展示总销量；完整保留 1000 行上限，不合并“其他”。
- 保持原生筛选器响应、交叉筛选范围、中文 Tooltip 和当前颜色方案不变。
- 不修改 Superset 核心前端，不改变任何数据表或指标口径。

## 验收

- 生成资产中 `SKU销售比例.viz_type = pie`，参数与 SPU 环形饼图合同一致，分组字段为 `sku`。
- 资产拓扑保持 9 个数据集、27 个图表、2 个看板，主看板关联 26 个图表。
- 生产导入后 26 个主看板 Chart Data API 均返回 HTTP 200。
- 浏览器中 `SKU销售比例` 显示为环形饼图，图例、标签、中文 Tooltip 和筛选响应正常。
